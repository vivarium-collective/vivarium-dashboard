## Goal

Migrate SMS_API_BASE to a parameterizable request via a dropdown list in workbench (targeted use case: setting up api's on other org HPC's)

**things to verify:**

- for a given simulation, you can choose from a dropdown list compute backends, which is 
    injected as the SMS_API_BASE for any deployment (aka compute backend). So for example:
     > AWS Gov Cloud (Production): would point to smscdk stack/sms-api-stanford namespace
     > AWS Gov Cloud (Development): would point to smsvpctest stack/sms-api-stanford-test namespace
     > CCAM would point to sms-api-rke namespace of sms-api (https://sms.cam.uchc.edu)

## Why this is needed

We seek to expose a variety of remote compute backends for simulations
that are dispatch-able in the vivarium-workbench, not just the viva-api.
